# Phase 16.0.1 Generation Quality Rubric

> 创建时间：Phase 16.0.1（2026-05-22）  
> 用途：评估生成质量，指导 prompt 迭代方向

---

## 评分维度（7 维）

### 1. 具体性（Specificity）

**定义**：生成内容是否使用了用户给出的动作、地点、原话、物件、时间节点。

| 分 | 说明 |
|----|------|
| 1 | 完全没有用户提供的具体细节，纯模板 |
| 2 | 用了少量细节，但大量模板句 |
| 3 | 用了主要细节，但偶有模板填充 |
| 4 | 大多数内容有具体细节支撑 |
| 5 | 每一段都能找到对应的用户材料 |

### 2. 克制感（Restraint）

**定义**：是否避免了空泛的煽情词汇和鸡汤句式。

| 分 | 说明 |
|----|------|
| 1 | 充斥「珍贵、永远、成长、意义、感动」等空泛词 |
| 2 | 部分段落煽情，但不至于油腻 |
| 3 | 总体克制，偶有套话 |
| 4 | 基本克制，语气真实 |
| 5 | 全篇克制，情绪来自细节而非直接煽情 |

### 3. 人味（Human Feel）

**定义**：句子是否有长短变化，是否像真人写的，而不是模板报告。

| 分 | 说明 |
|----|------|
| 1 | 每句结构相似，像流水账填空 |
| 2 | 有少量有个性的句子，但整体仍模板化 |
| 3 | 大部分句子自然，偶有模板痕迹 |
| 4 | 有节奏感，有停顿，有留白 |
| 5 | 读起来像一个有审美的人认真写的 |

### 4. 事实边界（Factual Integrity）

**定义**：是否没有编造用户没有提到的具体事实。

| 分 | 说明 |
|----|------|
| 1 | 大量编造具体事实（地点、日期、对话、人名等）|
| 2 | 少量编造，但影响可信度 |
| 3 | 无明显编造，偶有模糊处理 |
| 4 | 严格基于用户材料 |
| 5 | 严格基于材料 + 推测性表达用「也许/像是」标注 |

### 5. Mode 口吻（Mode Voice）

**定义**：是否符合各 mode 的特定写作人格。

| Mode | 期望口吻 |
|------|---------|
| family | 父母写给未来孩子，温柔，礼物感 |
| couple | 两个人之间，有暗号，有细节，克制 |
| personal | 自我回望，内省，清醒，不鸡汤 |
| memorial | 家族叙述视角，庄重，安静，不替 ta 说话 |

| 分 | 说明 |
|----|------|
| 1 | 完全不对，比如 memorial 让 ta 开口说话 |
| 2 | 总体对，但偶有口吻混乱 |
| 3 | 口吻基本一致 |
| 4 | 口吻准确，有 mode 特色 |
| 5 | 口吻准确 + 情感基调完全匹配 |

### 6. qualityReview 诚实度（Self-Assessment）

**定义**：AI 的自我质量评估（`extensions.qualityReview`）是否诚实准确。

| 分 | 说明 |
|----|------|
| 1 | 输入很少但 `riskOfFabrication` 为 low，严重误判 |
| 2 | 风险判断偏乐观，weaknesses 不充分 |
| 3 | 风险判断基本准确，weaknesses 部分到位 |
| 4 | 风险判断准确，weaknesses 诚实 |
| 5 | 风险准确 + weaknesses 诚实 + suggestionsForBetterInput 具体可操作 |

### 7. 可保存感（Archival Value）

**定义**：用户看到这份结果后，是否愿意把它保存或送人。

| 分 | 说明 |
|----|------|
| 1 | 生硬，用户不会保存 |
| 2 | 凑合，可以用但没有情感价值 |
| 3 | 可用，有一两处让人觉得「这句好」 |
| 4 | 有情绪价值，用户可能会保存 |
| 5 | 值得保存、分享、送人 |

---

## 综合评分

**总分 = 7 个维度的平均分**

| 总分 | 结论 |
|------|------|
| < 2.5 | 不可用，需要大修 prompt |
| 2.5 - 3.5 | 勉强可用，有明显问题需改进 |
| 3.5 - 4.0 | 可用，有改进空间 |
| 4.0 - 4.5 | 良好，小调优即可 |
| > 4.5 | 优秀，可以作为基线 |

---

## 评测注意事项

1. 每次评测使用**固定 fixture**（不同批次对比时保持输入不变）
2. 不同批次的评分由**同一人**完成（避免主观差异）
3. 评分后记录**具体例子**（哪句话得分高/低，为什么）
4. 每次结论附**下一轮 prompt 调整建议**
